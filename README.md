# E-PUSBONAT — GitHub Pages frontend

Paket ini adalah frontend statis terpisah. Tidak mengubah aplikasi FastAPI asli.

## Publikasi
1. Salin isi folder paket ini ke folder `docs/` di repositori GitHub yang benar.
2. Commit dan push setelah meninjau perubahan.
3. Di GitHub: Settings → Pages → Deploy from a branch → pilih branch utama dan folder `/docs`.

## Hal penting
- Tampilan ini belum terhubung ke backend/database.
- Jangan menaruh data pasien, rahasia, kredensial, `.env`, atau database di repositori publik.
- Login dan data bersama membutuhkan backend/API yang diamankan.
- Halaman Dashboard sengaja tidak menampilkan angka capaian fiktif.
